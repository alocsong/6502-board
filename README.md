This project implements a computer system build around the 6502 CPU, with references to classic architectures including the Apple II/IIe, etc.
It draws inspiration from classic vintage computer designs such as the Apple II.
The goal is to build a fully functional, retro computer from scratch, including CPU, memory, video display, I/O peripherals and firmware.

Key features:

1. Optimized upon the classic architecture, incorporating techniques including System Bus Double buffering;
2. CRTC functions are realized with the MC6845, using a novel timing control scheme.
